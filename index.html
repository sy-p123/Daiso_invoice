전대 매장 청구서 작업

계약마스터 전체를 붙여넣고 담당 부서·팀만 골라 작업합니다. 고정비는 자동, 실비는 직접 입력하고, 매장별 PDF로 저장합니다.

업무 순서 — 엑셀 작업 + HTML 페이지 작업

엑셀 계약마스터

  1. 당월 계약 변동 정리 당월 종료 도래 건 / 지난달 이전 종료인데 정리 안 된 건(연장이면 종료일 갱신, 종료면 계약상태를 공실로) / 당월 신규 시작 건
  2. 계약관리팀에 미수금 확인 요청A~W열까지만 값 붙여넣기로 발송합니다. X열부터는 자동 계산용입니다.
  3. 회신 미수금 크로스 체크 후 T열(정산잔액)에 반영
  4. 복사5행 머리글부터 마지막 계약까지, A~T열 이상. 복사 후에는 계약마스터를 고치지 마세요.

HTML 청구서 작업

  1. 청구월 설정오른쪽 위. 확인 필요 판정의 기준이라 가장 먼저 맞춥니다.
  2. 붙여넣고 불러오기"읽은 열" 안내에 정산잔액까지 있는지 확인합니다.
  3. 담당 부서·팀 선택
  4. 청구서 발행 항목 선택주황은 금액 확인, 빨강은 계약마스터 정리가 필요한 건입니다.
  5. 금액 수정월중 종료·시작 건 일할 계산, 수수료 계약 변동임대료
  6. 실비 입력항목·금액을 넣고 고정비와 함께 / 실비만 별도 / 이번 달 청구 안 함 중 하나를 고릅니다.
  7. 발행 전 점검'확인 필요' 목록이 비었는지, 청구서 장수와 합계가 맞는지 봅니다.
  8. 일괄 발행매장별 PDF로 저장됩니다.

발행 후

  1. 바로빌 세금계산서 발행
  2. 청구 내역 보관

계약 자체의 사실(기간·계약상태·기본 금액)은 엑셀에서 고치고, 이번 달에만 적용되는 금액(일할·실비·변동임대료)은 HTML 페이지에서 넣습니다. 그래야 계약마스터가 매달 흔들리지 않습니다.

1계약마스터 붙여넣기

계약마스터 5행(매장명·업체명이 적힌 머리글 줄)부터 마지막 계약까지 복사해 붙여넣으세요. 머리글이 없으면 불러오지 않습니다. 정산잔액까지 포함하면 미수금이 함께 반영됩니다. 열은 머리글 이름으로 찾으므로 열이 추가돼도 됩니다.

청구서 문구 설정 (납부기한 · 입금계좌 · 회사명 · 안내문구)
실비 항목 목록 고치기 (항목설정 시트와 맞추기)

한 줄에 항목명 ⇥ 과세구분 한 개씩입니다. 엑셀 항목설정 시트의 B·C열을 그대로 복사해 붙여넣어도 됩니다. 과세구분이 비어 있으면 과세로 처리합니다. 여기에 없는 항목도 입력 칸에 직접 타이핑할 수 있습니다.
